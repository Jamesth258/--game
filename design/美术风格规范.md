# 《逍遥仙》美术风格规范 v1

> 生效日期：2026-08-25 | 适用范围：所有新增/重做游戏美术资源（角色立绘 / 战斗背景 / 道具图标 / UI 元素）
> 核心原则：**所有图片必须共用同一套美术语境，禁止混用不同画风**

---

## 一、全局风格定义（源自 21 张正式立绘实测）

### 1.1 渲染技法
| 属性 | 规范 |
|------|------|
| **画种** | 写实古风仙侠游戏原画（Realistic Ancient Xianxia Game Key Art） |
| **笔触** | 精细厚涂（Thick-Paint Impasto），可见但融合的数字油画笔触，非平滑 3D 渲染 |
| **光影** | 电影级体积光（Volumetric/God Rays），强明暗对比，明确主光源方向，边缘光/轮廓光突出主体 |
| **细节密度** | AAA 级概念画质感，极高细节（布料褶皱、水珠、铠甲纹路、环境纹理），电影级景深虚化 |
| **氛围** | 沉浸式场景叙事，每个角色/场景自带完整世界观环境 |

### 1.2 色彩体系
- **基础规则**：高饱和但克制，冷暖对比强烈
- **Hero/Bright 侧**：冷蓝灰底 + 暖白/米白高光（如 hero_m1 山水峡谷）
- **Boss/Dark 侧**：暗紫/漆黑底 + 邪异绿/血红点缀（如 boss_1 冥界宫殿）
- **过渡区**：按主题自然衔接（金甲=金白、炎魔=赤橙、海怪=深蓝）
- **统一特征**：所有图片均带明确的单一情绪色板（mood palette），不杂乱

### 1.3 构图规范
| 资源类型 | 比例 | 方向 | 内容要求 |
|----------|------|------|----------|
| **角色立绘** | 3:4 或 9:16（竖版） | 竖向 | 全身像居中，含完整环境背景 |
| **战斗背景** | 16:9（横版） | 横向 | 全景环境，无主要前景角色，留中央空位供精灵站位 |
| **道具图标** | 1:1（方形） | 正方 | 物品居中，简洁背景 |

## 四、一致性铁律

1. **新增任何图片资源前必须查阅本规范**，确认风格前缀已正确附加。
2. **禁止混用风格**：不得出现 Q 版/卡通/扁平/3D 渲染等与厚涂写实古风不一致的风格。
3. **背景与角色必须同源**：每张战斗背景必须以对应敌人的立绘为参考（image-to-image 垫图），确保视觉一致性。
4. **版本更新**：本规范随美术迭代更新，每次修改在文首记录日期与变更摘要。

## 五、功能栏图标（2026-08-27 新增）

### 5.1 图标规格
| 属性 | 规范 |
|------|------|
| **尺寸** | 512×512 透明 PNG（圆形，透明角） |
| **底盘** | 统一青铜渐变圆环（12px 宽，左上高光）+ 深青黑径向渐变内区 |
| **图腾来源** | ImageGen 文本生图（768→缩放居中合成），每张独立主题对象 |
| **显示尺寸** | 顶栏 20px / 底栏 30px（CSS `border-radius:50%` + `object-fit:contain`） |
| **缓存戳** | `?v=8`（随图标更换递增） |
