# 人物属性与自由加点系统设计

> 来源：用户 2026-08-12 提出。6 项可自由加点属性，升级/突破时获得点数。
> 状态：框架已记录 + 已接入游戏「属性」界面（含加点、派生数值、战斗生效）。战斗公式细节标记为「待讨论」。

## 1. 六项可加点属性（用户原话定义）

| 属性 | 决定 / 机制（用户原话） |
| -- | -- |
| **体质** | 决定**物理防御力**与**生命值**；战斗中会损耗生命值，**休息时自动回复**生命值。 |
| **力量** | 决定**物理攻击力**。 |
| **灵魂** | 决定**精神攻击力**与**精神防御力**。 |
| **速度** | 决定**闪避率**与**先攻值**。<br>先攻值多段规则：<br>· 先攻值 = 对手 2 倍 → 当回合自己先行动 **2 次**再轮到对手<br>· 先攻值 = 对手 4 倍 → 先行动 **3 次**<br>· 先攻值 = 对手 6 倍 → 先行动 **4 次** |
| **悟性** | 决定**功法学习速度**与**灵力值**；使用功法攻击消耗灵力值；同时**提高挂机修炼的经验值加成**。 |
| **天命** | 决定**幸运值**；幸运值提高**闪避率**与**开宝箱出极品的概率**，同时**提高挂机修炼的经验值加成**。 |

> 用户说明：暂时先想到这 6 项，后续可能补充。

## 2. 派生属性映射（实现提案 · 待讨论）

基础属性初值均为 10，每突破一小阶得 `POINTS_PER_STAGE = 3` 点可分配。
派生命中值由「基础属性 + 境界加成」推导（境界 globalIndex 记为 `idx`）：

| 派生 | 公式（提案） | 说明 |
| -- | -- | -- |
| 生命上限 maxHp | `100 + 体质×12 + idx×8` | 体质主导 |
| 物理防御 def | `4 + 体质×0.8 + idx×1.2` | 体质主导 |
| 物理攻击 atk | `8 + 力量×1.6 + idx×2` | 力量主导 |
| 灵力上限 maxMp | `30 + 悟性×3 + idx×2` | 悟性主导（灵力=放功法消耗） |
| 精神攻击 spiAtk | `6 + 灵魂×1.4 + idx×2` | 灵魂主导 |
| 精神防御 spiDef | `3 + 灵魂×0.7 + idx×1.2` | 灵魂主导 |
| 先攻值 init | `= 速度` | 速度即先攻值 |
| 闪避率 eva | `min(45%, 速度×0.5% + 天命×0.3%)` | 速度+天命 |
| 幸运 luck | `= 天命` | 影响掉落/经验 |
| 挂机经验加成 | `悟性×0.5% + 天命×0.4%`（待做挂机系统） | 悟性+天命 |

> **待讨论点（见第 4 节）**：上述系数是否合适、是否要设属性上限、精神攻击/防御何时进战斗、挂机修炼与宝箱系统如何落地。

## 3. 已接入游戏的部分（代码位置：index.html）

- 玩家对象改为 6 基础属性 `con/str/sou/spd/com/des` + `spent`（已分配点数）。
- `recalcStats(player)`：由基础属性推导全部派生数值（见第 2 节公式）。
- 「属性」按钮弹窗 `showAttrModal()`：
  - 显示 6 属性，每行 `[−] [+]` 按钮；`+` 仅在 `可分配点数 > 0` 时可用，`−` 仅在属性 > 10（初值）时可回退。
  - 顶部显示「可分配点数 = 境界globalIndex × 3 − 已分配」。
  - 实时显示派生数值：生命/灵力上限、物理攻防、精神攻防、速度先攻、闪避率、战力。
  - 加点即 `recalcStats` + 刷新主页战力 + 存档。
- 战斗生效：
  - **速度多段先攻**：`beginRound()` 按先攻值比值生成行动队列（2×→2 段 / 4×→3 段 / 6×→4 段）。
  - **闪避**：`damage()` 加入 `随机 < 目标闪避率` 则未命中。
- 存档：`localStorage` 增加 6 属性 + `spent`，读档恢复后 `recalcStats`。
- 顺手修复：离线模式下原 `openModal/esc` 未定义（在线层早退），改为游戏内置全局弹窗系统。

## 4. 待与用户讨论的设计问题

1. **精神攻击/防御何时进战斗？** 目前战斗仅用物理攻防。建议：普攻=物理（力量），「功法/技能」=精神攻击（灵魂）打敌人精神防御；敌人也配精神攻防。是否认可双轴战斗？
2. **加点上限 / 洗点？** 属性是否封顶（如单项 ≤ 某值）？后期是否做「洗点」（重置已分配）功能？
3. **灵力消耗与回复**：功法费 10 灵力、每回合回 5，是否合适？悟性高是否该回得更快？
4. **速度多段触发门槛**：当前按「先攻值比值 ≥2× 才多段」，且 2×→2 段、4×→3 段、6×→4 段（公式 `段数 = floor(比值/2)+1`）。是否要更平滑（如 1.5× 就加 1 段）？
5. **挂机修炼系统**：悟性/天命提高经验加成——是否需要做一个「离线/挂机修炼」入口？
6. **宝箱/幸运系统**：天命提高「开宝箱出极品概率」——宝箱系统如何触发（战斗掉落？地图节点？）。
7. **派生系数调平衡**：第 2 节系数为初版，实战可能偏强/弱，需按试玩调。
