## 1. 六项可加点属性

| 属性 | 决定 / 机制 |
| -- | -- |
| **体质** | 物理防御力 + 生命值；战斗中损耗生命值，休息/离线结算时回满。 |
| **力量** | 物理攻击力。 |
| **灵魂** | 精神攻击力 + 精神防御力。 |
| **速度** | 闪避率 + 先攻值。<br>先攻值多段规则（比值 = 我方先攻 / 对手先攻）：<br>· 2× → 当回合先行动 **2 次**　· 4× → **3 次**　· 6× → **4 次**　· 8× → **5 次**　· 10× → **6 次**<br>· 极品特殊装备可额外增加「本回合行动次数」（`extraActions` 字段）。 |
| **悟性** | 功法学习速度 + 灵力值；功法攻击消耗灵力；提高挂机经验加成。 |
| **天命** | 幸运值；提高闪避率 + 开宝箱出极品概率；提高挂机经验加成。 |

> 可分配点数 = **境界小阶数 × 10 − 已分配**（`POINTS_PER_STAGE = 10`）。
> 单项属性**不设上限**（仅下限 = 初值 10，用于回退加点）。后期做「洗点」重置。

## 2. 派生属性公式（已定稿，用户给定）

基础属性初值均为 10，境界「小阶序号」记为 `idx`（= `CULTIVATION.realmFromXp(xp).globalIndex`，炼气一重天为 0）。

| 派生 | 公式 | 说明 |
| -- | -- | -- |
| 生命上限 maxHp | `100 + 体质×20 + idx×100` | 体质主导 |
| 物理防御 def | `10 + 体质×2 + idx×2.5` | 体质主导 |
| 物理攻击 atk | `20 + 力量×2 + idx×8` | 力量主导 |
| 灵力上限 maxMp | `100 + 悟性×20 + idx×100` | 悟性主导（灵力=放功法消耗） |
| 精神攻击 spiAtk | `20 + 灵魂×2 + idx×10` | 灵魂主导 |
| 精神防御 spiDef | `10 + 灵魂×1 + idx×2` | 灵魂主导 |
| 先攻值 init | `10 + 速度×2 + idx×2` | 速度主导 + 境界加成 |
| 闪避率 eva | `min(95%, 10% + idx×0.1% + 速度×0.1% + 天命×0.1%)` | 速度+天命+境界 |
| 幸运 luck | `= 天命` | 影响宝箱极品概率 |
| 挂机经验加成 xpBonus | `悟性×0.2% + 天命×0.2%` | 悟性+天命，比例叠加 |

> 默认角色（全 10，idx=0）示例：maxHp 300 / def 30 / atk 40 / maxMp 300 / spiAtk 40 / spiDef 20 / init 30 / 闪避 12% / 挂机加成 4%。

## 3. 战斗规则（已定稿）

- **单一血量轴**：普攻与功法都只扣「生命值」，生命归零即败。不设独立精神血量。
- **攻击类型**（由 `damage(attacker, target, mult, type)` 区分）：
  - 普攻 / 物理功法 → 用 `atk` 打 `def`。
  - 精神功法 → 用 `spiAtk` 打 `spiDef`。
  - 两者都扣同一 `hp`。
- **功法表 `SKILLS`**（灵力消耗各由功法而定，非固定）：
  - 旋风剑法 `xuanfeng`：物理，倍率 ×1.8，耗灵 12。
  - 玄阴指 `xuanyin`：精神，倍率 ×1.6，耗灵 15。
  - 玩家 `learned` 默认习得两者，`activeSkill` 为出战功法（在「功法」菜单切换）。
  - 敌人使用自身 `skill`（物理，耗灵 10）。
- **速度多段先攻** `beginRound()`：比值 ≥2× 时快者连动 `floor(比值/2)+1` 次（即 2×→2、4×→3、6×→4、8×→5、10×→6），再加 `extraActions`（装备）。
- **闪避**：`随机 < 目标闪避率` 则未命中（显示「闪避」）。

## 4. 挂机修炼系统（已定稿 + 已接入）

- **在线**：停留在游戏画面（主页 / 地图 / 战斗）即自动累加修为，速率 `ONLINE_XP_PER_SEC = 2/秒`，再乘 `(1 + 挂机加成)`。每 5 秒落盘一次。
- **离线**：按离开时长结算，速率 `OFFLINE_XP_PER_SEC = 1/秒`（约为在线一半），封顶 `OFFLINE_CAP_SEC = 12 小时`。进入游戏时弹「离线挂机结算」提示并回满气血。
- 实现：`player.lastSeen` 记录时间戳；`gainXp(amount, fullHeal)` 累加并重算派生；`applyOfflineXp()` 读取 `lastSeen` 结算。
- 悟性 / 天命越高，挂机经验加成比例越大（`xpBonus`）。
