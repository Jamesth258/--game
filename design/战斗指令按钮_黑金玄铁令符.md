## 二、设计定位：黑金玄铁令符

沿用项目既有的「黑金磨砂」色彩体系（与 `scroll-panel.css` 属性面板 A 同源），
把它从「弹窗面板」延伸到「指令按钮」，形成一套完整视觉语言。

| 层 | 做法 | 实现 |
|---|---|---|
| 底材 | 黑铁纵向渐变 + 顶部描金光晕 + 92° 竖向锻纹 | `background-image` 三层渐变 |
| 质感 | SVG 分形噪点磨砂（opacity .075，72×72 平铺） | `.battle-cmd::before` |
| 纹样 | 左上 / 右下 描金折角冠（云雷纹简形） | `.battle-cmd::after` 两个 SVG 背景定位 |
| 功法专属 | 右上角暗云纹水印（stroke-opacity .14） | `.battle-cmd.skill` 第 4 层背景 |
| 字形 | 楷体（`KaiTi/STKaiti/楷体`）+ 金字 #f3e7ca + 描黑边 + 金光外晕 | `font-family` + `text-shadow` |
| 灵力 | 金色「灵力珠」（径向渐变球 + 外发光）+ 成本数字 #e8c96a | `.cmd-cost::before` |
| 案几 | 指令栏本体改黑漆描金托底，上沿一线描金 | `.bar.battle-cmd-bar` |

配色令牌：主金 `#c9972f` ／ 亮金 `#f0d678` ／ 折角金 `#d8ac48` ／ 暖米白 `#f3e7ca` ／
朱红（危险）`#a83828` ／ 黑铁 `#2d2519 → #110d08`

## 三、交互状态

- **悬停**：金边燃亮（rgba(240,214,120,.85)）＋ 上浮 2px ＋ 外发光 16px
- **按下**：`translateY(0) scale(.975)`
- **置灰**（灵力不足 / 非我方回合）：玄铁蒙尘（去顶部光晕、去金字光晕、边框降到 .16）
  ＋ **灵力珠转朱红** ＋ 成本数字转朱红——一眼区分「没灵力」而非「没轮到」
- **JS 调整**：删掉 `setButtons()` 里的 `b.style.opacity` 内联写入（内联样式会盖掉 CSS 置灰态），
  统一交给 `.battle-cmd:disabled` 控制
