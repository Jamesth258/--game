# 《逍遥仙》百章剧情副本与奖励设计

> 改编自 2024–2026 年热门爆款仙侠小说，二次创作、名称与情节均做改编重组，规避抄袭。
> 配套数据由 `gen_story.js` 生成 → `js/story-data.js`（100 章 / 1000 关，已通过校验）。

---

## 1. 设计目标与总览

| 项 | 内容 |
|---|---|
| 章节数 | **100 章**（10 卷 × 10 章） |
| 每章关卡 | **10 个战斗关卡**（末关为 BOSS 关，经验 ×1.5） |
| 单关胜利奖励 | **经验值**（随章节递增，全 1000 关合计约 **55 万** 修为） |
| 每章通关奖励 | **功法三选一**（难度对应阶位）+ **装备三选一**（难度对应品质），玩家自主择一获取 |
| 改编蓝本 | 10 部当前热门仙侠小说（见 §2） |
| 与现有系统对接 | 功法取 `SKILLS_DB`、装备走 `player.genEquip()`、剧情解锁 `lockedUntil` 功法 |

## 4. 难度曲线映射（章节 → 奖励档位）

### 4.1 功法阶位（7 阶铺满 100 章）

| 章节 | 1–15 | 16–30 | 31–45 | 46–60 | 61–75 | 76–88 | 89–100 |
|---|---|---|---|---|---|---|---|
| 功法阶 | 黄阶 | 玄阶 | 地阶 | 天阶 | 王阶 | 皇阶 | 帝阶 |
| 覆盖章数 | 15 | 15 | 15 | 15 | 15 | 13 | 12 |

### 4.2 装备品质（5 品质铺满 100 章）

| 章节 | 1–15 | 16–37 | 38–59 | 60–81 | 82–100 |
|---|---|---|---|---|---|
| 品质 | 凡品 | 灵品 | 宝品 | 仙品 | 神品 |
| 覆盖章数 | 15 | 22 | 22 | 22 | 19 |

### 4.3 单关经验（胜利奖励）

`base = 20 + 章节×8`；章内第 `lv` 关 `exp = round(base × (1 + (lv-1)×0.05))`；第 10 关（BOSS）再 ×1.5。

- 第 1 章单关：28 → 62（首章合计 ≈ 424）
- 第 50 章单关：≈ 420 → 945
- 第 100 章单关：≈ 820 → 1845
- 全 1000 关经验合计 ≈ **550,170**（接入 `gainXp()` / `CULTIVATION` 经验曲线，数值可按挂机节奏再平衡）

## 5. 奖励规则详述

### 5.1 每关胜利 → 经验
战斗胜利结算时调用 `gainXp(levelExp, false)`，仅加修为不回满。

### 5.2 每章通关 → 三选一
通关第 10 关（BOSS）后弹出**双选奖励界面**：

**① 功法三选一（reward.skills，3 个 `SKILLS_DB` id）**
- 取本章对应阶位的功法池（如第 1 章取黄阶池）。
- 池内**优先取 `lockedUntil = dungeon / exchange` 的"剧情副本获取"功法**——这正是此前 27 条剧情副本功法的发放出口。
- **排除开局即赠送的 8 本入门功法**（`player.DEFAULT_LEARNED`），保证奖励永远有意义。
- 玩家择一 → 写入 `player.learned`（已学可在功法界面装备，上限 6）。

**② 装备三选一（reward.equip，3 个 `{slot, rarity}`）**
- 3 个选项为**不同部位**（武器/护甲/法宝/战靴轮转）+ 本章对应品质。
- 玩家择一 → 调用 `genEquip(slot, rarity)` 生成具体装备，进背包/可穿戴。
- 品质随章节从凡品一路升到神品（详见 §4.2）。

> 设计为"玩家自主选择"而非随机发放，契合需求"可供玩家自主选择获取"。

## 6. 数据文件与生成器

### 6.1 `js/story-data.js`（由 `gen_story.js` 生成，勿手改）
```
const STORY_CHAPTERS = [ /* 100 章对象 */ ];
const STORY_VOLUMES  = [ /* 卷总览，UI 目录用 */ ];
const STORY_BY_CH    = { 1: {...}, 2: {...}, ... };  // ch -> chapter 查表
```
单章对象字段：
```
{
  ch, volume, volumeName, inspiredBy, realmName,
  tier, tierName,            // 功法阶（1黄~7帝）
  rarity, rarityName,        // 装备品质（0凡~4神）
  title, plot,               // 章节名 + 一句话剧情梗概
  levels: [10 个经验值],     // 末位为 BOSS 关
  reward: {
    skills: [3 个功法 id],    // 三选一
    equip:  [3 个 {slot, rarity}] // 三选一
  }
}
```

### 6.2 重新生成
```
node gen_story.js
```
生成器会：读取 `js/skills-data.js` 的 `SKILLS_DB` 按阶分组 → 按章节映射阶位/品质 → 旋转取样三选一 → 写出 `js/story-data.js`，并打印覆盖统计与非法引用校验（应 0）。

## 7. 与游戏已有系统的对接点（接入建议）

| 系统 | 对接方式 |
|---|---|
| 功法库 | 三选一功法 id 来自 `SKILLS_DB`（130 种，7 阶）；`lockedUntil=dungeon/exchange` 的 27 条通过剧情副本解锁 |
| 装备系统 | 三选一装备 `{slot, rarity}` → `player.genEquip(slot, rarity)`，沿用 5 品质 × 4 部位 × 极品连动逻辑 |
| 经验/境界 | 单关经验 → `gainXp()`，喂入 `CULTIVATION` 大境界阶梯（炼气→宇宙国主） |
| 战斗 | 每章 10 关可复用现有 `startBattle`/`makeEnemy`，按章节难度缩放敌方数值（建议在 `makeEnemy` 注入 `chapterIdx` 做强度曲线） |
| UI 入口 | 在主城 hub 新增"剧情副本"页：目录显示 10 卷 / 100 章 / 每章 10 关进度；通关第 10 关触发三选一弹窗 |
