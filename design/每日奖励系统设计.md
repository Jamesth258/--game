# 每日奖励系统设计

> 归属：`js/daily.js`（核心逻辑）+ `js/hub.js`（菜单/商店钻石专区）+ `js/player.js`/`js/core.js`/`js/main.js`（字段/存档/启动）+ `index.html`（引入）。
> 测试：`test/daily.test.js`（无头回归，41 项断言全过）。

## 一、货币：钻石（diamond）
- 新增货币 `player.diamond`，与灵石（gold）并列，专用于**商城消费**。
- 产出仅来自每日奖励（签到里程碑 7/14、在线 5/15/60 分钟）；不在挂机/战斗掉落。
- 商城「钻石专区」按钻石计价出售 4 种抽奖宝箱（见第四节）。

## 二、第一重 · 每日签到
- **每日签到即送灵石 = 当前境界等级 × 100**。
  - 「境界等级」取修炼体系扁平小阶序号 `globalIndex + 1`（开局炼气一重天 = 1，满级宇宙国主 = 总阶数 163）。如需改用「大境界序号」改 `realmLevel()` 一处即可。
- **月度累计签到里程碑**（自动发放，无需手动领）：

| 当月累计签到 | 奖励 |
|---|---|
| 3 次 | 功法抽奖宝箱 ×1 |
| 5 次 | 装备抽奖宝箱 ×1 |
| 7 次 | 商城钻石 ×1000 |
| 14 次 | 商城钻石 ×2000 |
| 20 次 | 装备抽奖宝箱 ×2 + 功法抽奖宝箱 ×2 |

- 防重复：每个里程碑用 `monthClaimed[count]` 标记，达成后只发一次；同一天重复点签到不重复发灵石（`signedToday` 守卫）。

## 三、第二重 · 在线时长奖励（达成即自动发放）
定时器每秒累计 `onlineSecToday`（创建角色界面不计），跨过未领取阈值即发奖并 `saveGame()` + `showToast` 提示。

| 当日在线 | 奖励 |
|---|---|
| 满 5 分钟 | 10 钻石 |
| 满 15 分钟 | 20 钻石 |
| 满 30 分钟 | 装备抽奖宝箱 ×1 |
| 满 60 分钟 | 经验宝箱 ×1 + 灵石宝箱 ×5 + 30 钻石 |

- 每阈值用 `onlineClaimed[min]` 标记，只发一次；次日 0 点重置。

## 四、宝箱与商城钻石专区
- 宝箱直接复用 `worldboss.js`：`openSkillChest`（随机习得未拥有功法）、`openEquipChest`（随机品质装备）、`openStoneChest`（+200~800 灵石）、`openExpChest`（+2000~10000 修为）。
- 商店「钻石专区」：`buyDiamondChest(type)`，单价 功法/装备 200 钻、灵石/经验 50 钻；钻石不足则按钮禁用。

## 五、重置与存档
- `ensureDaily()`：以本地日期 `YYYY-MM-DD` 为日锚点、月份 `YYYY-MM` 为月锚点。
  - 跨天 → 重置 `signedToday / onlineSecToday / onlineClaimed`；若同时跨月 → 一并重置 `monthSignCount / monthClaimed`。
  - 同日跨月（月末 23:59→00:00 边界）→ 仅重置月状态。
- 字段随 `saveGame()` 存入 `wuxia_save`（`diamond`、`daily`）。

## 六、新增文件/改动
- 新增 `js/daily.js`：`ensureDaily / realmLevel / dailySignIn / dailyTickSeconds / initDaily / openDailyRewardScreen / dailyGrant`。
- `js/player.js`：加 `diamond:0`、`daily:null`。
- `js/core.js`：`saveGame` 增 `diamond/daily`；新增 `showToast`。
- `js/main.js`：恢复 `diamond/daily`；初始化末尾 `initDaily()` 启动计时。
- `js/hub.js`：每日奖励菜单 `modal_daily → openDailyRewardScreen`；商店加钻石余额与「钻石专区」+ `buyDiamondChest`。
- `index.html`：在 `worldboss.js` 后引入 `js/daily.js`。
